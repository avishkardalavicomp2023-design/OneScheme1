# 🇮🇳 One Scheme – One Nation One Scheme

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)
![Bootstrap](https://img.shields.io/badge/Bootstrap-7952B3?style=for-the-badge&logo=bootstrap&logoColor=white)

A modern web application that helps citizens discover, compare, and check eligibility for various **Government and Private Welfare Schemes** through a single, user-friendly platform.

The project aims to simplify access to scholarships, financial assistance, employment, agriculture, startup, and other welfare schemes by bringing them together in one place.

---

# 📌 Features

- 🔍 Search schemes by name
- 📂 Explore schemes by category
- ✅ Eligibility Checker
- 📊 Compare multiple schemes
- 📄 Detailed scheme information
- 📱 Responsive UI using Bootstrap
- ⚡ Fast client-side filtering
- 🎨 Modern and clean interface

## ✅ Eligibility Checker

Allows users to enter information such as

- Age
- Gender
- Income
- Occupation
- Academic Level
